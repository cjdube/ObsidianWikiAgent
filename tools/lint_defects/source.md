# Agent engineering notes — collected

A single collected source file. Every page in this fixture vault cites it.

The filename is deliberately not date-shaped: `check_source_coverage` only
requires a dated page for a dated source, and this pack has no reason to
exercise that rule.

Contents are intentionally thin. The pages, not this file, carry the planted
defects — the judgment pass reads pages, and has no tool that reads raw/.
